# Jogo Criptex

Um jogo mobile de palavras desenvolvido com **React Native** e **Expo**, inspirado em desafios de lógica e dedução. O objetivo é descobrir as palavras secretas utilizando as dicas fornecidas e o menor número possível de tentativas.

> Desafie sua lógica. Decifre a palavra. Supere seus recordes.

---

## 📋 Sobre o projeto

O **Criptex** é um jogo de raciocínio em que o jogador deve descobrir palavras escondidas por meio de tentativas e dicas. O projeto foi desenvolvido com foco em proporcionar uma experiência simples, intuitiva e divertida, explorando conceitos de gerenciamento de estado, navegação, animações e persistência de dados em React Native.

Além da mecânica principal, o jogo registra o desempenho do jogador, oferecendo uma experiência mais dinâmica e motivadora.

## 🚀 Como executar o projeto

### Clone o repositório

```bash
git clone https://github.com/douglas-moura/jogo-criptex.git
```

### Acesse a pasta

```bash
cd jogo-criptex
```

### Instale as dependências

```bash
npm install
```

ou

```bash
yarn
```

### Execute o projeto

```bash
npm start
```

ou

```bash
npx expo start
```

Depois basta abrir o aplicativo utilizando o **Expo Go** ou executar em um emulador Android/iOS.
